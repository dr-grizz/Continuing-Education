# Existing-account learner OAuth verification

October 21, 2026. Local branch: `codex/canvas-learner-login`. Scope: [ADR 0009](../adr/0009-canvas-learner-login.md). This records local checks, not hosted acceptance or live CU login.

| Check                                | Result   | Evidence and limits                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Learner OAuth integration            | Pass     | `npm run test:learner-auth`; isolated database, mocked Canvas. Covers narrow identity scope despite enabled staff course reads, no email adoption, one profile under concurrent login, state/nonce/replay/expiry, role separation, hashed session rotation/revocation, deactivation, shared callback, HTTPS cookies, CSRF and mock-selector rejection. |
| Registration and simulated payment   | Pass     | Same isolated suite: verified learner registration, idempotent simulated payment, private learning/operation ownership, and rejection of another learner's payment/operation access. No Stripe API call, real payment or Canvas enrollment.                                                                                                            |
| Staff OAuth regression               | Pass     | `LEARNER_AUTH_MODE=mock npm run test:auth`; existing staff suite plus explicit staff/learner coexistence in the new learner suite.                                                                                                                                                                                                                     |
| Canvas connector regression          | Pass     | `LEARNER_AUTH_MODE=mock npm run test:canvas`; isolated database and mocked provider.                                                                                                                                                                                                                                                                   |
| Migrations                           | Pass     | `LEARNER_AUTH_MODE=mock npm run test:migrations`; fresh/adopted databases, repeat/concurrent runs and schema drift checks.                                                                                                                                                                                                                             |
| Local data preservation              | Pass     | Backup archive created and listed successfully before migration `021_canvas_learner_auth`; pre/post hashes using original columns verified all rows and values across 29 existing application tables. Backup restoration was not repeated in this change.                                                                                              |
| Typecheck, formatting and build      | Pass     | `npm run typecheck`, `npm run format:check`, `npm run build`, `git diff --check`.                                                                                                                                                                                                                                                                      |
| Focused browser/accessibility checks | Pass     | `WEB_URL=http://localhost:3050 npm run test:a11y -- --grep 'CU learner OAuth'`: 20 tests across Chrome light/dark/mobile, Firefox and WebKit. Fixtures cover sign-in keyboard focus and errors, email-less identity/settings, checkout-return session display, staff-to-learner navigation and staff learner names. Axe scans cover these states.      |
| Local configuration smoke check      | Pass     | `/api/demo-session` reports Canvas mode, configured, and no learner session when signed out. Ignored local configuration enables `LEARNER_AUTH_MODE=canvas`.                                                                                                                                                                                           |
| Live CU OAuth and upstream MFA       | Not run  | Requires the person signing in through the configured institutional flow. Mocked exchange does not prove live developer-key acceptance or fresh MFA.                                                                                                                                                                                                   |
| Full Stripe sandbox return           | Not run  | The browser fixture proves email-less session UI handling; it does not prove a live Checkout round trip.                                                                                                                                                                                                                                               |
| Manual screen-reader review          | Not run  | Required before shared release. Automated scans and keyboard assertions do not establish screen-reader usability or WCAG conformance.                                                                                                                                                                                                                  |
| Azure deployment                     | Deferred | Azure remains the selected host; subscription, region, access-gate configuration, tooling, capacity validation and hosting-plan approval remain unresolved.                                                                                                                                                                                            |

The local website/API were started at `http://localhost:3050` and `http://localhost:3051`. Existing demo registrations are preserved without automatically linking them to authenticated CU accounts.
