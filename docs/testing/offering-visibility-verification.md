## Existing local database

Before applying the additive `022_offering_visibility` migration, a PostgreSQL custom-format backup was saved locally as `backups/pre-offering-visibility-20261021-d2ce545d.dump` (ignored by Git). It was fully restored to a separate disposable database and verified against the original rows across 31 application tables before that database was removed.

After `npm run db:migrate`, the original column values, row counts and row hashes across those 31 tables matched the pre-migration snapshot. Every existing offering has `listed=true`; original publication, mapping, staff, learner and payment records were preserved. The local application was restarted on ports 3050/3051. Backup contents and snapshot hashes are not included in this report.
